# Меняемся

«Меняемся» — веб-сервис для безденежного обмена товарами и услугами. Пользователи размещают лоты, указывают, что хотят получить взамен, и находят участников с подходящими предложениями.

Проект команды `"Деловые люди"` по предмету `"Проектный практикум"`, 7 семестр ИРИТ-РТФ УрФУ.  
Заказчик: `"ИТого"`.

## Для кого

Сервис предназначен для тех, кто хочет обменять ненужные вещи или свои услуги на что-то полезное: студентов, семей, специалистов, фрилансеров и сторонников осознанного потребления.

## Возможности

- Регистрация, подтверждение почты, вход и восстановление пароля.
- Личный кабинет и публичные профили участников со статусом подтверждения почты, списками лотов, отзывами, рейтингом и завершёнными обменами. До подключения соответствующих серверных выдач эти разделы используют моки.
- Настройки имени, региона, контактов и аватара с предпросмотром и удалением изображения.
- Лоты товаров и услуг с описанием, фотографиями, категорией, регионом, способом передачи и ориентировочной стоимостью.
- Пошаговое создание и редактирование лота, выбор обложки при создании, сохранение текстового черновика, отправка на модерацию, удаление и повторная публикация.
- При редактировании серверного лота новые фото и варианты обмена добавляются при сохранении. Сохранённые вложения удаляются прямо с соответствующих элементов, с подтверждением и без потери несохранённого текста; нужно оставить хотя бы одно фото и один вариант обмена. Порядок сохранённых фото задаётся сервером, новые идут в конец.
- После успешной отправки — экран статуса модерации с данными лота, вариантами обмена, переходом к своим лотам и возможностью разместить следующий. Лот на проверке можно редактировать.
- Несколько вариантов обмена одновременно: конкретные лоты, категории, пожелания тегами и готовность рассмотреть предложения участников. Можно выбрать до 10 лотов и до 10 категорий. Пожелания добавляются отдельными тегами по Enter и удаляются крестиком: до 10 тегов и 300 символов суммарно. Пробелы и запятые внутри пожелания сохраняются.
- Галерея фотографий, миниатюры желаемых лотов со ссылками и сведения владельца.
- Локальный центр уведомлений с категориями, отметкой прочтения и очисткой; серверная доставка событий пока отсутствует.
- Административная панель с таблицами пользователей и лотов на модерации: поиск по имени, фильтр статуса, пагинация, заморозка/разморозка, просмотр данных проверяемого лота, одобрение и отклонение с причиной; управление иерархией категорий.
- FAQ с поиском по вопросам и правила сервиса.
- Главная с реальными категориями и десятью последними опубликованными предложениями для гостей; для участников — подборка рекомендаций на моковых данных.
- Публичный каталог товаров и услуг с поиском, категориями и подкатегориями, регионом, ценой, доставкой/самовывозом, сортировкой и постраничной загрузкой; отдельная страница рекомендаций с поиском и фильтрами на моковых данных.

Интерфейс адаптирован для компьютеров, планшетов и телефонов, поддерживает светлую и тёмную темы. Элементы управления оформлены в едином стиле. Защищённые разделы доступны после входа, административная панель — только администраторам.

## Планируемые возможности

- Исключение собственных лотов из каталога для авторизованного участника с корректными страницами и общим количеством результатов.
- Сортировка по реальному рейтингу владельца.
- Списки собственных лотов со статусами и публичных объявлений участника, история обменов и отзывов.
- Персональные рекомендации лотов с учётом интересов пользователя.
- Автоматическая оценка рыночной стоимости.
- Предложения обмена и переписка между участниками.
- Подтверждение завершения обмена, отзывы и рейтинг на основе реальных сделок.
- Жалобы, аудит решений и уведомления о модерации; возврат причины отклонения владельцу.
- Уведомления о сообщениях, предложениях, результатах модерации и состоянии обменов.

## Технологический стек

- **Frontend:** Next.js 16.4.2 (App Router), React 19.2.3, TypeScript 5.9.3, SCSS Modules, архитектура Feature-Sliced Design.
- **Backend:** Java 21, Spring Boot 3.5, Spring Security, Spring Data JPA, JWT.
- **База данных:** PostgreSQL 17, миграции Liquibase.
- **Запуск:** Docker Compose; frontend также можно запускать локально через npm.

## Структура репозитория

```text
backend/       серверное приложение Spring Boot
frontend/      приложение Next.js
compose.yaml   запуск frontend, backend и PostgreSQL
.env.example   пример настроек окружения
```

## Запуск проекта

Понадобятся Docker и Docker Compose. В корне репозитория создайте `.env` из примера:

```bash
cp .env.example .env
```

Заполните учётные данные PostgreSQL, настройки SMTP и отправителя писем, секреты access- и refresh-токенов. Значение `POSTGRES_DB` должно совпадать с именем базы в `SPRING_DATASOURCE_URL`. Для запуска через Compose адрес базы — `db:5432`, публичный адрес приложения — `http://localhost:3000`. Файл `.env` содержит секреты и не должен попадать в Git.

Запустите сервисы из корня репозитория:

```bash
docker compose up --build
```

При первом запуске PostgreSQL создаёт базу данных, а backend применяет миграции Liquibase.

| Сервис | Адрес |
| --- | --- |
| Приложение | http://localhost:3000 |
| Backend API | http://localhost:8080/api/v1 |
| Swagger UI | http://localhost:8080/swagger-ui/index.html |

Просмотр журналов и остановка сервисов:

```bash
docker compose logs -f db backend frontend
docker compose down
```

База данных хранится в Docker volume `postgres_data`, загруженные изображения — в `uploads_data`. При обычной остановке данные сохраняются; `docker compose down -v` удаляет их вместе с этими volume.

## Локальный запуск frontend

Понадобятся Node.js и npm. Из корня репозитория запустите backend и базу данных:

```bash
docker compose up db backend --build
```

В отдельном терминале запустите frontend:

```bash
cd frontend
npm ci
npm run dev
```

Приложение доступно на http://localhost:3000. Адрес сервера задаётся переменной `NEXT_PUBLIC_API_URL`, по умолчанию — `http://localhost:8080`. Пример настройки находится в `frontend/.env.example`; при необходимости создайте на его основе `frontend/.env.local`.

Для локальной production-сборки из директории `frontend`:

```bash
npm run build
npm start
```

```bash
npm run format:styles # исправить только CSS и SCSS
npm run lint          # также включает ошибки форматирования
```
